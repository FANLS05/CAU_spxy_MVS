# 换个标注概念(极简版)

把 `window` 换成别的 —— `door`、`wall`、`balcony`……**只改两个地方,而且必须改得一致。**

---

## 第 0 步:变量

```powershell
$sam   = "D:\ProgramData\anaconda3\envs\sam3\python.exe"        # 出 mask
$py    = "C:\Users\FANLS\.conda\envs\basic_env\python.exe"      # 回灌点云
$root  = "D:\code\point_cloud\0916"
$imgs  = "$root\work\food\dense\images"
$scene = "$root\work\food\dense\sparse"

$concept = "door"                    # ← 只改这一行的值
$mdir    = "$root\masks_$concept"    # ★ 输出目录跟着概念走,别复用 masks\
$ovdir   = "$root\out\ov_$concept"
```

---

## 第 1 步:出 mask(SAM 3)

先单张,看图确认标的是你要的东西:

```powershell
& $sam "$root\tools\sam3_masks.py" `
  --images $imgs --out $mdir `
  --text $concept --expect-size 3781 2788 `
  --limit 1 --overlay-dir $ovdir
```

打开 `$ovdir\IMG_2430.png`。**青色落在你要的物体上,才继续。**

批量:

```powershell
& $sam "$root\tools\sam3_masks.py" `
  --images $imgs --out $mdir `
  --text $concept --expect-size 3781 2788 `
  --overlay-dir $ovdir --save-json "$root\out\report_$concept.json"
```

---

## 第 2 步:回灌点云

```powershell
& $py "$root\tools\mask_to_points.py" `
  --scene $scene --mask-dir $mdir `
  --mask-mode index --class-names $concept --depth-tol-hist --min-conf 0.9 `
  --out "$root\out\$concept.ply" --labels "$root\out\$concept.npy" `
  --save-json "$root\out\stats_$concept.json" `
  --vis
```

窗口里底色是照片色,**青色就是新概念的标签**。

## 多个概念

`--text` 可以给多次,**顺序就是类别 id 的顺序**(1、2、3…)。两个工具必须写成一样的顺序:

```powershell
# 出 mask。默认 --priority first:先列出的概念赢重叠,所以按「具体 → 宽泛」写
& $sam "$root\tools\sam3_masks.py" --images $imgs --out "$root\masks_multi" `
  --text window --text door --text wall --expect-size 3781 2788 `
  --overlay-dir "$root\out\ov_multi"

# 回灌。--class-names 的顺序**必须一模一样**,且用逗号分隔、不加空格
& $py "$root\tools\mask_to_points.py" --scene $scene --mask-dir "$root\masks_multi" `
  --mask-mode index --class-names "window,door,wall" --min-conf 0.9 `
  --out "$root\out\multi.ply" --labels "$root\out\multi.npy" `
  --vis
```

颜色按类别 id 循环(1 = 青,2 = 下一个 PALETTE 色……),窗口里会打图例。

---

## 两个静默的坑

**1. 换了概念一定要换 `--out` 目录,或者加 `--overwrite`。**

`sam3_masks.py` 默认**跳过已存在的 `<图名>.png`**(为了断点续跑)。还往老 `masks\`
里写的话,它一张都不会重跑,你拿到的是**上一个概念的 mask** —— 而
`mask_to_points` 那边一切正常、不报任何错,只是标签整个是错的。

**2. `--class-names` 顺序错了不会有任何报错。**

下游按**类别 id** 取名字(`names[val-1]`)。顺序一错,所有类别的名字整体错位,
点云上看起来完全正常。多概念时对着 `--text` 逐项核一遍。

> 判断新概念好不好用,看 `report_<概念>.json` 里的 `dead_concepts`:
> 非空说明某个概念**在所有图上一个实例都没检出**,大概率是提示词不对。
